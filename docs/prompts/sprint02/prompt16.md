Задача B-09 из docs/tasks/SPRINT-02.md. Контракт ответа и коды ошибок — оттуда же,
из раздела «Согласованные значения». Прочитай их перед тем, как писать код.

Создай серверный Route Handler GET /api/snapshot на Node runtime.

Что он делает:
  — открывает WebSocket-соединение к AISStream;
  — сразу после открытия соединения отправляет подписку на район из конфигурации
    с фильтром типа PositionReport;
  — возвращает первое полученное сообщение как есть, без преобразования:
    HTTP 200 { ok: true, raw: <сообщение или null>, collectedAt }.

Срок — 15 секунд от начала обработки запроса, включая соединение и отправку подписки.
Если соединение живо, подписка отправлена, а сообщений не пришло — raw: null,
это успех, не ошибка.

Ошибки — HTTP 502 { ok: false, attemptedAt, error: { code, message } } с текстами
ровно из задания:
  no_api_key      «Ключ AISStream не настроен»  — сразу, соединение не открывается
  connect_failed  «Не удалось подключиться к источнику»
  disconnected    «Соединение с источником разорвано»
  provider_error  «Источник вернул ошибку»
  internal        «Внутренняя ошибка сервера»

Ошибка сокета до открытия соединения возвращается немедленно, не по истечении срока.
Сырой текст ошибки провайдера или исключения в message не попадает.

Ключ читай только на сервере. Не логируй его, не возвращай в ответе, не подставляй
в сообщения об ошибках.

Закрывай соединение и таймеры при любом исходе: успех, ошибка, отмена запроса.

Границы: несколько сообщений не собирай — это следующее занятие. Преобразование
сообщения в судно не пиши. Интерфейс, карту и карточку не трогай.

Критерий: ключа сейчас нет, поэтому запрос должен вернуть 502 с кодом no_api_key.
Запусти сервер, выполни запрос и покажи ответ целиком.
