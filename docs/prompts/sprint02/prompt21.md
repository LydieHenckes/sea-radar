Задача B-12 из docs/tasks/SPRINT-02.md. Подумай, прежде чем писать код — здесь пять разных исходов, и результат обязан завершиться ровно один раз.

Разверни reader в сборщик. Правила сбора:

  — срок 15 секунд от начала серверной обработки запроса, включая установление соединения и отправку подписки; константа живёт в конфигурации;
  — до 100 уникальных судов с валидной позицией; при достижении 100 сбор завершается немедленно, не дожидаясь конца срока; константа там же;
  — одна позиция на id: остаётся самая новая по time_utc, сравнение с точностью до миллисекунды. Новое сообщение заменяет объект судна целиком — все поля из нового сообщения. При равных метках остаётся принятая первой;
  — сто сообщений об одном судне — это одно судно, и сбор идёт до конца окна.
  Завершение:

  — конец окна при живом соединении и отправленной подписке — успех, reason 'window_elapsed', даже если судов ноль;
  — лимит 100 — успех, reason 'limit_reached', truncated true;
  — ошибка провайдера, разрыв соединения до штатного завершения, отмена запроса клиентом — НЕ возвращают собранный частичный набор как успех;
  — результат завершается ровно один раз: события, пришедшие после завершения, его не меняют;
  — во всех исходах без исключения закрываются соединение и таймеры.

Источник событий и часы остаются параметрами сборщика — теми, что заложены на прошлой неделе. Не заменяй их на глобальные WebSocket и Date.
Формат успешного ответа endpoint:
  { ok: true, vessels, collectedAt, windowSeconds: 15, count, truncated,
    reason: 'window_elapsed' | 'limit_reached' }
Пустой успех — тот же формат с vessels: [] и count: 0. Это успех, не ошибка.
windowSeconds — значение константы окна, а не фактическая длительность: при завершении по лимиту там всё равно 15.
collectedAt и attemptedAt берутся из переданных часов, не из Date.now().

Ошибки — прежние: HTTP 502, коды и тексты из задания, без изменений.

Границы: интерфейс и кнопку не трогай — следующая задача. Наборы между запросами не храни и не накапливай. Автоматических повторов и переподключения не добавляй. Тестов не пиши.

Критерий: выполни живой запрос и покажи мне count, reason, truncated и один элемент vessels целиком. Запусти.
