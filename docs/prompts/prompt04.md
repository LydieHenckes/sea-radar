Создай типизированную структуру судна ровно с этими полями, помести файл с описанием типов в соответствующую папку. Тип судна :
  id          — строка
  name        — строка или null (пустая строка превращается в null)
  lat, lon    — числа
  speedKnots  — число или null
  courseDeg   — число в диапазоне [0, 360) или null
  timestamp   — строка ISO 8601 с зоной
  source      — 'demo' | 'aisstream'

Ноль и null — разные вещи, тип должен это выражать.

откорректируй, если необходимо константу MAP_CONFIG, для совместимости с типом судна.
