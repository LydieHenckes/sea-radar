# Sea Radar

## Stack

- Node.js 24
- Next.js avec App Router
- React
- TypeScript en mode `strict`

## Commandes

```text
npm install
npm run dev
npm run build
npm start
```

L’application de développement est disponible sur `http://localhost:3000`.

## Limites de la semaine actuelle

Cette semaine couvre uniquement le socle de l’application et le premier incrément local : carte du détroit de Douvres, un navire de démonstration et sa fiche au clic. Ne pas ajouter de données réelles, de serveur, de bouton de chargement ou de fonctionnalités hors de ce périmètre.

## Secrets

Ne jamais lire, afficher, copier ou inclure de secrets dans les fichiers, les sorties de commande ou les réponses.
